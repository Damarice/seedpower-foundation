## EXECUTIVE SUMMARY

This document provides a production-ready technical architecture for the SeedPower Foundation website, corrected from v1.1 to address integration, accessibility, security, and content accuracy issues identified during independent review.

The architecture uses **Next.js 15 with App Router**, **React 19**, **TypeScript strict mode**, and **Tailwind CSS 4** with a fully CSS-first design token system. All components are built for accessibility (WCAG 2.2 AA), performance (Core Web Vitals), and maintainability. Routing is based on actual discovered content, not assumed future capabilities.

**Implementation must not begin until client decisions in Section 14 have been confirmed and this document has been approved.**

## SECTION 1 — VERIFIED TECHNOLOGY STACK

### 1.1 Core Framework & Runtime

| Component | Specification | Rationale |
|---|---|---|
| **Node.js** | LTS 22.x (or latest LTS at project start) | Stable; required by Next.js 15; LTS receives 18+ months active support |
| **Next.js** | 15.x with App Router | Latest stable; App Router for streaming, parallel routes, metadata API |
| **React** | 19.x | Latest stable; included with Next.js 15 |
| **React DOM** | 19.x | Paired with React 19 |
| **TypeScript** | 5.7+ | Strict mode enforced; no implicit any; null safety required |

### 1.2 Styling & Design Tokens

| Component | Specification | Integration |
|---|---|---|
| **Tailwind CSS** | 4.x (CSS-first configuration) | Requires `@tailwindcss/postcss` PostCSS plugin |
| **PostCSS** | 8.4+ | Required for Tailwind 4; configured in `postcss.config.mjs` |
| **CSS Custom Properties** | Native CSS variables in `styles/tokens.css` | Single source of truth for all design tokens |

**Tailwind CSS 4 is CSS-first.** There is no `tailwind.config.ts`. All custom breakpoints, colours, spacing, typography, shadows, and radii are declared inside `@theme { }` in `styles/tokens.css`. Tailwind 4 reads these `@theme` variables and generates utility classes automatically.

### 1.3 Typography

| Component | Implementation | Notes |
|---|---|---|
| **Manrope** | `next/font/google` with `weight: ['600', '700']` | Self-hosted; zero layout shift |
| **Inter** | `next/font/google` with `weight: ['400', '500', '600']` | Self-hosted; zero layout shift |

Both fonts load via `next/font/google`. No third-party font requests at runtime.

### 1.4 Forms & Validation

| Component | Selection | Scope |
|---|---|---|
| **React Hook Form** | 7.x | Contact form only (multi-field validation) |
| **Zod** | 3.x | Form validation schemas, API request validation, env var parsing |
| **Native HTML forms** | Preferred for simple cases | Single-field inputs; server-side validation required either way |

### 1.5 Icons & Animations

| Component | Selection | Notes |
|---|---|---|
| **Icons** | Inline SVG or SVG sprite | No icon library; keeps bundle small |
| **Animations** | CSS transitions + `@keyframes` | No Framer Motion; CSS handles all animation needs |

### 1.6 Deployment

| Environment | Specification | Notes |
|---|---|---|
| **Recommended** | Vercel (paid hobby or Pro) | Native Next.js support; automatic deployments; CDN included |
| **Alternative** | Self-hosted Node.js (AWS/GCP/DigitalOcean) | Requires Docker + CI/CD setup |

**Note on static exports:** If the site is deployed as a static export (`output: 'export'` in `next.config.ts`), Next.js does not perform on-demand image format conversion (WebP/AVIF). Image optimisation via `next/image` requires a Node.js server or Vercel edge runtime. The recommended Vercel deployment provides this automatically.

- `--spacing-4` → `p-4`, `m-4`, `gap-4`, `px-4`, etc.
- `--radius-md` → `rounded-md`
- `--breakpoint-tablet` → `tablet:` responsive prefix
- `--breakpoint-desktop` → `desktop:` responsive prefix

No `tailwind.config.ts` is needed or used.

#### **Button.tsx** (Level 2)

`Button` is for interactive actions (form submit, toggle). `ButtonLink` is for navigation and anchor links. They are separate components and are not combined with an `asChild` prop.

```typescript
// components/buttons/Button.tsx
import React from 'react'
import Link from 'next/link'
import { cn } from '@/lib/cn'

type ButtonVariant = 'primary' | 'secondary' | 'ghost'
type ButtonSize = 'sm' | 'md'

interface ButtonProps extends React.ButtonHTMLAttributes<HTMLButtonElement> {
  variant?: ButtonVariant
  size?: ButtonSize
  children: React.ReactNode
}

interface ButtonLinkProps {
  href: string
  variant?: ButtonVariant
  size?: ButtonSize
  external?: boolean
  className?: string
  children: React.ReactNode
  onClick?: () => void
}

const variantStyles: Record<ButtonVariant, string> = {
  primary:   'bg-brand text-white hover:bg-brand-hover active:bg-brand-active',
  secondary: 'bg-[#1a1a1a] text-white hover:bg-[#333333] active:bg-[#111111]',
  ghost:     'border-2 border-brand text-brand hover:bg-brand-surface',
}

const sizeStyles: Record<ButtonSize, string> = {
  sm: 'px-4 py-2 text-sm font-semibold',
  md: 'px-6 py-3 text-base font-semibold',
}

const baseClasses =
  'inline-flex items-center justify-center rounded-[4px] transition-colors no-underline ' +
  'min-h-[44px] min-w-[44px] ' +
  'focus-visible:outline focus-visible:outline-2 focus-visible:outline-offset-3 focus-visible:outline-brand ' +
  'disabled:bg-[#cccccc] disabled:text-[#505050] disabled:cursor-not-allowed'

export const Button = React.forwardRef<HTMLButtonElement, ButtonProps>(
  ({ variant = 'primary', size = 'md', className, ...props }, ref) => (
    <button
      ref={ref}
      className={cn(baseClasses, variantStyles[variant], sizeStyles[size], className)}
      {...props}
    />
  )
)
Button.displayName = 'Button'

export const ButtonLink: React.FC<ButtonLinkProps> = ({
  href,
  variant = 'primary',
  size = 'md',
  external,
  className,
  onClick,
  children,
}) => {
  const classes = cn(baseClasses, variantStyles[variant], sizeStyles[size], className)

  if (external) {
    return (
      <a
        href={href}
        target="_blank"
        rel="noopener noreferrer"
        className={classes}
        onClick={onClick}
      >
        {children}
        <span className="sr-only"> (opens in new tab)</span>
      </a>
    )
  }

  return (
    <Link href={href} className={classes} onClick={onClick}>
      {children}
    </Link>
  )
}
```

```typescript
  item: NavItem

  const [open, setOpen] = useState(false)
  const containerRef = useRef<HTMLDivElement>(null)
  const triggerRef = useRef<HTMLButtonElement>(null)
  const dropdownId = `dropdown-${item.label.toLowerCase().replace(/\s+/g, '-')}`

  const close = useCallback(() => setOpen(false), [])

      if (!containerRef.current?.contains(e.relatedTarget as Node)) close()

      containerRef.current?.removeEventListener('focusout', handleFocusOut)

      <button
        ref={triggerRef}
        onClick={() => setOpen((v) => !v)}
        onKeyDown={(e) => {
          if (e.key === 'Enter' || e.key === ' ') {
            e.preventDefault()
            setOpen((v) => !v)
          }
        }}
        aria-expanded={open}
        aria-haspopup="true"
        aria-controls={dropdownId}
        className="px-5 py-2 text-[15px] font-medium text-[#1a1a1a] hover:text-brand
                   focus-visible:outline focus-visible:outline-2 focus-visible:outline-offset-3
                   focus-visible:outline-brand transition-colors flex items-center gap-1 bg-transparent border-none cursor-pointer"
      >
        {item.label}
        <svg
          className={`w-4 h-4 transition-transform ${open ? 'rotate-180' : ''}`}

          fill="currentColor"
          viewBox="0 0 20 20"

                href={child.href}
                role="menuitem"
                onClick={close}

        </ul>
      )}
    </div>
  )
}
```

- Mouse: click trigger opens/closes dropdown; click outside or on a link closes it

```typescript
  },

    label: 'Give',
    href: '/give',
    children: [
      { label: 'Donate', href: '/give/donate' },
      { label: 'Events', href: '/give/events' },
    ],
  },
  { label: 'Contact', href: '/contact' },
]

export const MobileNav: React.FC<MobileNavProps> = ({ id, onClose }) => {
  const [expandedItems, setExpandedItems] = React.useState<Set<string>>(new Set())
  const drawerRef = useRef<HTMLElement>(null)
  const closeButtonRef = useRef<HTMLButtonElement>(null)

  // Lock background scroll
  useEffect(() => {
    document.body.style.overflow = 'hidden'
    return () => { document.body.style.overflow = '' }
  }, [])

  // Move focus into drawer on open
  useEffect(() => {
    closeButtonRef.current?.focus()
  }, [])

  // Escape to close
  useEffect(() => {
    const handleKey = (e: KeyboardEvent) => {
      if (e.key === 'Escape') onClose()
    }
    document.addEventListener('keydown', handleKey)
    return () => document.removeEventListener('keydown', handleKey)
  }, [onClose])

  // Focus trap: Tab and Shift+Tab stay inside the drawer
  useEffect(() => {
    const drawer = drawerRef.current
    if (!drawer) return

    const focusable = drawer.querySelectorAll<HTMLElement>(
      'a[href], button:not([disabled]), textarea, input, select, [tabindex]:not([tabindex="-1"])'
    )
    const first = focusable[0]
    const last = focusable[focusable.length - 1]

    const handleTab = (e: KeyboardEvent) => {
      if (e.key !== 'Tab') return
      if (e.shiftKey) {
        if (document.activeElement === first) {
          e.preventDefault()
          last.focus()
        }
      } else {
        if (document.activeElement === last) {
          e.preventDefault()
          first.focus()
        }
      }
    }

    drawer.addEventListener('keydown', handleTab)
    return () => drawer.removeEventListener('keydown', handleTab)
  }, [expandedItems]) // Re-bind when expanded items change (new items become focusable)

  const toggleExpanded = (label: string) => {
    setExpandedItems((prev) => {
      const next = new Set(prev)
      next.has(label) ? next.delete(label) : next.add(label)
      return next
    })
  }

  return (
    <>
      {/* Overlay */}
      <div
        className="fixed inset-0 bg-black/40 z-40"
        onClick={onClose}
        aria-hidden="true"
      />

      {/* Drawer */}
      <nav
        id={id}
        ref={drawerRef}
        role="dialog"
        aria-label="Navigation menu"
        aria-modal="true"
        className="fixed left-0 top-0 h-screen w-full max-w-sm bg-white
                   shadow-[0_8px_32px_rgba(0,0,0,0.16)] z-50 overflow-y-auto
                   transition-transform duration-300"
      >
        {/* Close button */}
        <div className="flex items-center justify-between px-6 py-4 border-b border-[#e0e0e0]">
          <span className="text-base font-semibold text-[#1a1a1a]">Menu</span>
          <button
            ref={closeButtonRef}
            onClick={onClose}
            className="w-11 h-11 flex items-center justify-center rounded-[4px]
                       focus-visible:outline focus-visible:outline-2 focus-visible:outline-offset-3
                       focus-visible:outline-brand"
            aria-label="Close navigation menu"
          >
            <svg className="w-6 h-6" fill="currentColor" viewBox="0 0 20 20" aria-hidden="true">
              <path fillRule="evenodd" d="M4.293 4.293a1 1 0 011.414 0L10 8.586l4.293-4.293a1 1 0 111.414 1.414L11.414 10l4.293 4.293a1 1 0 01-1.414 1.414L10 11.414l-4.293 4.293a1 1 0 01-1.414-1.414L8.586 10 4.293 5.707a1 1 0 010-1.414z" clipRule="evenodd" />
            </svg>
          </button>
        </div>

        {/* Nav items */}
        <div className="px-4 py-4 space-y-1">
          {navItems.map((item) => (
            <div key={item.href}>
              {item.children ? (
                <>
                  <button
                    onClick={() => toggleExpanded(item.label)}
                    aria-expanded={expandedItems.has(item.label)}
                    className="w-full text-left px-4 py-3 text-base font-medium text-[#1a1a1a]
                               hover:bg-[#f9faf8] rounded-[4px] flex items-center justify-between
                               focus-visible:outline focus-visible:outline-2 focus-visible:outline-offset-3
                               focus-visible:outline-brand min-h-[44px] border-none bg-transparent cursor-pointer"
                  >
                    {item.label}
                    <svg
                      className={`w-4 h-4 transition-transform ${expandedItems.has(item.label) ? 'rotate-90' : ''}`}
                      aria-hidden="true"
                      fill="currentColor"
                      viewBox="0 0 20 20"
                    >
                      <path fillRule="evenodd" d="M7.21 14.77a.75.75 0 01.02-1.06L11.168 10 7.23 6.29a.75.75 0 111.04-1.08l4.5 4.25a.75.75 0 010 1.08l-4.5 4.25a.75.75 0 01-1.06-.02z" clipRule="evenodd" />
                    </svg>
                  </button>
                  {expandedItems.has(item.label) && (
                    <ul className="pl-4 space-y-1 py-1">
                      {item.children.map((child) => (
                        <li key={child.href}>
                          <Link
                            href={child.href}
                            onClick={onClose}
                            className="block px-4 py-2 text-[15px] text-[#666666] hover:text-brand
                                       focus-visible:outline focus-visible:outline-2 focus-visible:outline-offset-3
                                       focus-visible:outline-brand rounded-[4px] no-underline min-h-[44px]
                                       flex items-center transition-colors"
                          >
                            {child.label}
                          </Link>
                        </li>
                      ))}
                    </ul>
                  )}
                </>
              ) : (
                <Link
                  href={item.href}
                  onClick={onClose}
                  className="block px-4 py-3 text-base font-medium text-[#1a1a1a]
                             hover:bg-[#f9faf8] focus-visible:outline focus-visible:outline-2
                             focus-visible:outline-offset-3 focus-visible:outline-brand
                             rounded-[4px] no-underline min-h-[44px] flex items-center transition-colors"
```

**Drawer accessibility behaviour:**
- Opens: focus moves to the close button (first focusable element)

```typescript
// app/api/contact/route.ts
import { NextRequest, NextResponse } from 'next/server'
import { Ratelimit } from '@upstash/ratelimit'
import { Redis } from '@upstash/redis'
import { contactFormSchema } from '@/lib/validation'

// Upstash Redis rate limiter: 5 submissions per hour per IP
const ratelimit = new Ratelimit({
  redis: Redis.fromEnv(),
  limiter: Ratelimit.slidingWindow(5, '1 h'),
  analytics: false,
})

function getClientIp(request: NextRequest): string {
  // On Vercel, the real client IP is in x-forwarded-for.
  // The first value in the comma-separated list is the client IP.
  // Do not trust this header on a server where you control the proxy config,
  // but on Vercel it is set by the edge infrastructure and is reliable.
  const forwarded = request.headers.get('x-forwarded-for')
  if (forwarded) return forwarded.split(',')[0].trim()
  return 'unknown'
}

export async function POST(request: NextRequest) {
  try {
    // Rate limiting
    const ip = getClientIp(request)
    const { success } = await ratelimit.limit(`contact:${ip}`)
    if (!success) {
      return NextResponse.json(
        { error: 'Too many submissions. Please try again later.' },
        { status: 429 }
      )
    }

    // Parse and validate request body
    const body = await request.json()
    const result = contactFormSchema.safeParse(body)
    if (!result.success) {
      return NextResponse.json(
        { error: 'Invalid form data. Please check your inputs.' },
        { status: 400 }
      )
    }

    const { name, email, subject, message } = result.data

    // Honeypot check (already validated by Zod, but explicit for clarity)
    if (result.data.honeypot) {
      // Silently return 200 to avoid giving bots feedback
      return NextResponse.json({ success: true })
    }

    // ── DELIVERY STEP ─────────────────────────────────────────
    // Pending implementation decision: select one of the following:
    //   (a) Send via transactional email (Resend, Postmark, SendGrid)
    //   (b) Store in database (Supabase, PlanetScale) for manual review
    //   (c) Forward to a webhook (Zapier, Make)
    // Do not proceed with this route until the delivery mechanism
    // has been selected and the recipient email confirmed with the client.
    // ─────────────────────────────────────────────────────────
    console.log('Contact form submission received:', { name, email, subject })

    // Success: reflect actual processing state once delivery is wired up
    return NextResponse.json({
      success: true,
      message: 'Your message has been received and will be reviewed shortly.',
    })
  } catch (error) {
    // Log internally; never expose error details to the client
    console.error('Contact form error:', error)
    return NextResponse.json(
      { error: 'Something went wrong. Please try again.' },
      { status: 500 }
    )
  }
}
```

### 8.4 Spam Prevention

- **Honeypot field:** A hidden text input named `honeypot` is included in the form but hidden from sighted users via CSS. Automated bots that fill all fields will fill the honeypot. The server rejects any submission where `honeypot` is non-empty.
- **Rate limiting:** Upstash Redis sliding window, 5 requests per hour per IP.
- **Server-side Zod validation:** Rejects malformed or oversized payloads before any processing.

The honeypot field must be hidden using CSS positioning (`position: absolute; left: -9999px`), not `display: none` or `visibility: hidden`, which some bots detect. It must have an accessible label to avoid screen readers reading it unexpectedly — use `aria-hidden="true"` on the field and its label.

## SECTION 9 — ACCESSIBILITY REQUIREMENTS

### 9.1 WCAG 2.2 AA Target

All pages must meet **WCAG 2.2 AA** as minimum. Verification combines automated scanning and manual testing.

- **Automated:** axe (via `jest-axe` in unit tests, `@axe-core/playwright` in E2E tests)
- **Manual keyboard:** Tab, Shift+Tab, Enter, Space, Escape — verify all interactive elements are reachable and operable
- **Manual screen reader:** NVDA + Firefox or VoiceOver + Safari — verify navigation, headings, form labels, error messages, and dynamic content
- **Colour contrast:** WebAIM Contrast Checker — all combinations verified against design token values in Section 1 of `visual-design-direction.md`

Accessibility checks run continuously throughout development, not only in a final audit phase.

### 9.2 Semantic HTML

One `<h1>` per page, above the fold. Headings must not skip levels. Use `<main>` for page content, `<nav>` for navigation landmarks, `<footer>` for the footer. Use `<section>` with `aria-labelledby` to group related content.

```tsx
<main>
  <section aria-labelledby="programmes-heading">
    <h2 id="programmes-heading">What We Do</h2>
    <article>
      <h3>Education Centers</h3>
      <p>…</p>
    </article>
  </section>
</main>
```

### 9.3 Keyboard Navigation

| Element | Expected behaviour |
|---|---|
| All interactive elements | Reachable via Tab |
| Buttons | Enter or Space to activate |
| Links | Enter to follow |
| Desktop dropdown trigger | Enter or Space to open; Escape to close; Tab through items |
| Mobile drawer | Enter/Space on hamburger to open; Escape to close; Tab/Shift+Tab trapped inside |
| Form inputs | Tab to focus; validation shown on blur or submit |

Skip navigation link ("Skip to main content") is the first focusable element on every page. It is visually hidden by default and visible on focus.

### 9.4 Touch Targets

All interactive elements (buttons, links, form controls, hamburger, close, chevron) have a minimum tap target of 44×44px. Where the visible element is smaller (e.g. inline links in body text), padding expands the clickable area without changing visible text size.

### 9.5 Images

Every `<Image>` has a descriptive `alt` attribute. Decorative images use `alt=""`. Alt text describes content and context, not visual format.

### 9.6 Reduced Motion

All transitions and transforms are suppressed under `prefers-reduced-motion: reduce`. Both the `@media` override in `styles/tokens.css` (zeroes transition variables) and the CSS override in `app/globals.css` cover this.

```typescript
  weight: ['400', '500', '600'], // 'weight', not 'weights'
  variable: '--font-body',
  display: 'swap',
})

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en" className={`${manrope.variable} ${inter.variable}`}>
      <body>{children}</body>
    </html>
  )
}
```

The CSS variables `--font-heading` and `--font-body` are set by `next/font` on the `<html>` element. The global styles in `app/globals.css` reference them as `font-family: var(--font-heading)` for headings and `font-family: var(--font-body)` for body text.

### 11.6 Core Web Vitals Targets

| Metric | Target | Strategy |
|---|---|---|
| **LCP** (Largest Contentful Paint) | < 2.5s | Preload hero image with `priority`; self-host fonts via `next/font`; minimize render-blocking CSS |
| **INP** (Interaction to Next Paint) | < 200ms | Minimize main-thread JavaScript; defer non-critical code |
| **CLS** (Cumulative Layout Shift) | < 0.1 | Specify `width` and `height` on all images; reserve space for fonts (`font-display: swap`) |

FID (First Input Delay) was deprecated in May 2024 and replaced by INP as a Core Web Vital. FID is not a target.
